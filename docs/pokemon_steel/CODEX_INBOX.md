# Pokémon Steel — Codex Inbox

## Rules for scheduled Codex runs

1. Read this file at the start of every scheduled Pokémon Steel run.
2. Treat entries as **instructions or design notes**, not automatic permission to broaden the current milestone.
3. If an entry is relevant to the current milestone and low-risk, incorporate it.
4. If an entry belongs to a later milestone, leave it untouched and mention it in the run report.
5. Never alter `master`; work only on the active Pokémon Steel development branch specified by the task.
6. Do not delete old entries. When an item is completed, move it to the Completed section with the commit SHA.
7. If an entry conflicts with locked design canon or existing implementation, stop and report the conflict rather than guessing.

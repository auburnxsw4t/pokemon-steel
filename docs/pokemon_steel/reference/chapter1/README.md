# Chapter 1 map construction reference

`Pokemon_Steel_Chapter1_Map_Construction_V2.zip` is the current approved
construction reference for the Southwoods and Route 1 map pass. It
contains the frozen construction notes, semantic grids, metrics, and preview
images supplied with the project sources.

Do not treat the archive as ROM-ready map data. Written Pokémon Steel design
documents override text embedded in concept images. The functional maps use
the archive's topology, dimensions, traversal pressure, feature zones, and
required trainer positions while translating its semantic cells into existing
Emerald metatiles. Decorative tiles remain replaceable placeholders.
